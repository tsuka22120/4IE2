## Verilog HDL 記述ルール

### 1. `always @(*)` の使用禁止

- 組み合わせ回路では `always @(a, b, sel)` のように感度リストを明示する
- 順序回路では `always @(posedge iClk)` を使用する

### 2. ラッチ防止

- `case` 文には必ず `default` を付与する
- `if` 文には必ず `else` 節を付ける
- 組み合わせ回路の `always` ブロック内で全出力に初期値を割り当てる

### 3. 命名規則

| 対象         | プレフィクス   | 例                     |
| ------------ | -------------- | ---------------------- |
| 入力ポート   | `i`            | `iClk`, `iToggleSw`    |
| 出力ポート   | `o`            | `oDigit`, `oPattern`   |
| 内部ワイヤ   | `w_`           | `w_alu_result`         |
| 内部レジスタ | `r_`           | `r_acc`                |
| パラメータ   | 大文字スネーク | `OP_ADD`, `DATA_WIDTH` |

### 4. モジュール構成

- 1ファイル1モジュール
- ファイル名はモジュール名と一致させる
- テストベンチは `tb_<module名>.v` とする

### 5. コメント

- 各モジュール先頭に目的・入出力の説明コメントを記述
- 主要なロジックにはコメントを付与
