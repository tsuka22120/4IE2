# Project Context — 8ビットALU

## プロジェクト概要

- **科目**: 集積回路設計（高専4年）
- **課題**: 4命令以上のALUを自ら設計し、FPGA上にVerilog HDLで構築
- **目標**: S評価（最高評価）
- **作成日**: 2026-02-20
- **現在のフェーズ**: 実装・テストベンチ完了 → シミュレーション実行待ち

## 要件サマリ

1. **命令数**: 12命令（要件4以上の3倍）
2. **レジスタ**: ACC(8bit), IX(8bit), SR(4bit: CF/ZF/SF/OF)
3. **インストラクション**: 16bit（OpCode[15:9] + IX[8] + Operand[7:0]）
4. **実行トリガ**: SW17立ち上がりエッジ（edge_detector で同期化）
5. **表示**: SW18/S1による3モード7セグ表示（ダイナミック点灯）
   - SW18=OFF → インストラクション（16進4桁）
   - SW18=ON, S1=OFF → IX（16進2桁, 上位00）
   - SW18=ON, S1=ON → ACC(上位2桁) + SR(下位2桁)
6. **加点要素**: SW1〜16による直接命令入力 ✅採用済み
7. **禁止**: `always @(*)` → 感度リスト明示で対応 ✅確認済み
