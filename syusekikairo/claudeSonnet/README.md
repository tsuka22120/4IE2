# FPGA 設計レポート自動生成ツール

## 概要

全加算器(FA)と全減算器(FS)の FPGA 設計とレポートを自動生成する Python ツールです。

## 生成されるファイル

### 1. Verilog ファイル (.v)

- `half_adder.v` - 半加算器モジュール
- `full_adder.v` - 全加算器モジュール (HA を 2 つ使用)
- `half_subtractor.v` - 半減算器モジュール
- `full_subtractor.v` - 全減算器モジュール (HS を 2 つ使用)
- `top.v` - トップモジュール (モード切替機能付き)

### 2. ピン配置ファイル

- `gowin_pins.cst` - Gowin FPGA 用ピン配置ファイル

### 3. テストベンチ

- `tb_top.v` - シミュレーション用テストベンチ

### 4. レポート

- `FPGA設計レポート_全加算器・全減算器.docx` - Word レポート

## 必要なライブラリ

```bash
pip install python-docx
```

## 実行方法

```bash
python generate_fpga_report.py
```

## ピン配置 (Gowin GW1NR-9)

| 信号名 | ピン番号 | 機能                          |
| ------ | -------- | ----------------------------- |
| iA     | 69       | SW1 - 入力 A                  |
| iB     | 68       | SW2 - 入力 B                  |
| iCy_Br | 57       | SW3 - 桁上げ/借用入力         |
| iMode  | 56       | SW4 - モード切替 (0:FA, 1:FS) |
| oLD1   | 10       | LD1 - 和/差                   |
| oLD2   | 11       | LD2 - 桁上げ/借用             |

## 動作仕様

### モード切替

- **SW4 = 0**: 全加算器モード
  - 入力: A, B, Cin (桁上げ入力)
  - 出力: Sum (和), Carry (桁上げ)
- **SW4 = 1**: 全減算器モード
  - 入力: A, B, Bin (借用入力)
  - 出力: Diff (差), Borrow (借用)

### LED 表示

- LED は負論理 (論理 1 で点灯、論理 0 で消灯)
- Verilog 内で自動的に反転処理を実装済み

## 設計の特徴

1. **階層設計**: 半加算器/半減算器を基本モジュールとして、全加算器/全減算器を構成
2. **モジュール化**: 再利用可能なコンポーネント設計
3. **ハードウェア対応**: LED 負論理仕様への自動対応
4. **完全なドキュメント**: 理論、実装、検証を含む包括的なレポート

## レポート構成

1. 表紙 (提出日、氏名、課題名)
2. 目的
3. 原理 (HA, FA, HS, FS, モード切替、LED 反転)
4. 使用器具
5. 実験方法
6. 実験結果 (全コード、ピン配置、テストベンチ)
7. 考察

## 次のステップ

1. Gowin EDA でプロジェクトを作成
2. 生成されたファイルをインポート
3. 合成・配置配線を実行
4. FPGA に書き込み
5. 実機で動作確認
6. レポートを提出
